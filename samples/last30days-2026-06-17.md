## 4. ⚡ 早盘启示（开盘前 5 条 actionable 信号）

### 🟢 可关注的方向

1. **A 股多 Agent 投研赛道实质性升温** — [TradingAgents-AShare](https://github.com/KylinMountain/TradingAgents-AShare)（578★）和 [lzwme/finance-quant-skills](https://github.com/lzwme/finance-quant-skills)（98★）都把 A 股数据 + Agent 接好了。对应可买：**AI 投顾 / 金融 IT** 板块（如 [同花顺](https://www.eastmoney.com/)、[财富趋势](https://www.eastmoney.com/)），逻辑是私募开始用多 Agent 做研究 → 卖方研究服务被压缩 → 买方 IT 支出上升。

2. **因子挖掘工业化拐点已到** — [alphagen](https://github.com/ICT-FinD-Lab/alphagen) RL 因子 + [QuantGPT](https://github.com/Miasyster/QuantGPT) agent 因子 + [AlphaPurify](https://github.com/eliasswu/AlphaPurify) 清洗三件套到位，**传统"研究员手挖因子"模式估值要重估**。对应可关注：**券商系金工团队** + 量化独角兽（九坤、幻方、明汯的私募产品）。

3. **券商接口 Agent 化是结构性趋势** — [Robinhood 开放 AI agent](https://www.reuters.com/business/robinhood-opens-platform-ai-agents-trading-cred) + [eltdx 把通达信做成 MCP](https://github.com/electkismet/eltdx) + [pytrader 东方财富](https://github.com/jadepeng/pytrader) — **A 股实盘 agent 接入成本断崖式下降**。可关注：本地化部署的 QMT / PTrade 接入服务、MCP 类中间件。

### 🔴 风险 / 避坑

4. **LLM Agent 失控是当前最大的"灰犀牛"** — HN 头条 [AI agent bankrupted operator（1460 pts）](https://news.ycombinator.com/item?id=48500012) + [Live brokerage 实验亏钱](https://deemwar.com/insights/inside-an-autonomous-ai-trading-floor) 都不是孤例。**任何用 LLM agent 接实盘的团队，要把单日最大亏损硬上限写进 agent prompt**，不能依赖 LLM 自己"理性"。HN 高赞解决方案：[Forge guardrails](https://github.com/nexusflow/forge) 把 8B 模型 agent 任务从 53% 提到 99%。

5. **预测市场进入监管视野，国内不碰** — Google 工程师 + George Santos 两个案子说明 CFTC / DOJ 已开始主动执法。**国内目前预测市场（体彩除外）仍属灰色地带，机构资金不要碰**；海外 Polymarket / Kalshi 头寸要纳入合规报备。
